## Sobre o projeto

O projeto apresenta a Hiper Check do Brasil, suas soluções de inteligência de crédito, análise de risco, negativação e monitoramento empresarial.

A plataforma foi desenvolvida para oferecer uma experiência moderna, responsiva e intuitiva, facilitando o acesso às informações e o contato entre empresas e especialistas comerciais.

## Tecnologias utilizadas

- Next.js 16
- React
- JavaScript
- CSS3
- HTML5
- Next.js Image
- Font Awesome
- Vercel (deploy)

## Funcionalidades

- Navbar responsiva com menu mobile

## Executando localmente

### Pré-requisitos

- Node.js compatível com Next.js 16
- npm

### Instalação

Clone o repositório:

```bash
git clone URL_DO_REPOSITORIO
```

Acesse a pasta do projeto:

```bash
cd NOME_DA_PASTA
```

Instale as dependências:

```bash
npm install
```

Inicie o ambiente de desenvolvimento:

```bash
npm run dev
```

Acesse:

http://localhost:3000

## Build de produção

Para gerar uma versão otimizada:

```bash
npm run build
```

Para iniciar o servidor de produção:

```bash
npm run start
```

## Responsividade

O projeto utiliza CSS com media queries para adaptar seus componentes a diferentes resoluções.

Os ajustes específicos estão centralizados em:

```text
app/responsive.css
```

Os estilos principais e a identidade visual são definidos em:

```text
app/globals.css
```
